## 使い方

`rust/t4s-core/src/isdbs.rs` の `cs_tsid()` / `bs_tsid()` に反映済み。
CS は従来 `TSID=0`（自動）で DEMUX が空でしたが、実 TSID を FED に渡すことで
選局対象の TS を固定できる。
